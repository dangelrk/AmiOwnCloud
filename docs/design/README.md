# Historische Planungsdokumente

Die Dateien in diesem Ordner sind Konzept- und Planungsdokumente aus der
Zeit vor der Aufteilung des früheren Monorepos in AmiCloudCore, AmiCloud,
AmiOwnCloud und AmiVCS. Sie werden unverändert aufbewahrt: Pfade darin
(z. B. `client/apps/`, `libs/`, `docs/architecture/`) beziehen sich auf das
alte Monorepo – heute liegen die Bibliotheken unter `core/` (AmiCloudCore)
und die Programme unter `apps/`. Aktuelle Doku: `README.md`, `docs/BUILD.md`,
`docs/INSTALL.md`, `docs/user/`.
